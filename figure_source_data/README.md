# Figure source values

The CSV files preserve the stored plotting values exactly.
`value_provenance.csv` records original relative paths, physical lines and
columns; `frozen_inputs/` includes unplotted conditions. Intervals are stored
results. Figure 1 combines cached development diagnostics with schematic
dependency masks; mask colors do not represent measured Fisher magnitudes.

`figures/` contains individual vector figures. The finite-calibration panels
show complete weight, coefficient-distance and raw-KL trajectories. The G1
figure shows all eleven full-pool sources, with source607 repeated on a
separate absolute scale. The article and Supplement are held separately.
