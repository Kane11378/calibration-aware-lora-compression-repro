# Recorded environment

Static verification uses Python 3.10 or newer and its standard library.
The mathematical source files require NumPy, SciPy and threadpoolctl for separate use.
The JSON version records and `requirements-scientific.txt` describe the
original scientific runtime; they do not establish that the experiments can
be repeated with the assets in this release snapshot alone.

Individual vector figures are supplied as stored artifacts. Font subsets in
the PDFs retain their original rights. No rendering font is distributed.
